# コード検索

- 処理の意図から実装箇所を探す場合は、`jrg PATTERN PATH --about "探す処理" --json` を優先する。
- 正確な識別子・文字列の全件検索には `rg` を使う。
- jrg の結果が不足する場合は、検索語を広げて rg でも確認する。結果がないことを、実装が存在しない証拠にしない。
- jrg が未導入、認証未設定、または API エラーの場合は rg で調査を続ける。
- jrg は検索意図・候補のパス・ソースを TypeSafe API に送信する。外部送信を認めているコードだけを検索対象にする。
- 認証は環境変数 `TYPESAFE_API_KEY` またはプロジェクトの `.jrgenv` を使用する。キーの内容を表示・プロンプトに転記しない。
